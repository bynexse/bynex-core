# Bynex OS Demo v0.2.0

Klickbar Fas 1-demo av Bynex – det sammanhängande AI-operativsystemet för bygg- och fastighetsbranschen.

## Nytt i v0.2.0

- Bynex Connect med företagskanaler och projektchatt
- Skicka meddelanden direkt i demon
- AI-svar och handlingsbaserade meddelanden
- AI Status: fråga alla i projektet hur arbetet går
- Röstmemo-demo
- AI-översättning för 15 språk
- Connect integrerat i snabbåtgärder och sidnavigation
- Tid, Projekt, Arbetsledaren, Platschef, Material, ÄTA och Offert från v0.1.0

## Starta

1. Installera Node.js 20 eller senare.
2. Packa upp ZIP-filen.
3. Öppna terminalen i mappen `bynex-os-v0.2.0`.
4. Kör:

```bash
npm install
npm run dev
```

5. Öppna http://localhost:3000
