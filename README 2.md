# Bynex Demo v0.1.0

En klickbar Fas 1-demo av Bynex – AI-operativsystemet för byggbranschen.

## Ingår

- Dashboard
- Projekt och gemensamt UE-flöde
- Bynex Tid med simulerad GPS-stämpling
- Bynex Arbetsledaren
- Bynex Platschef
- AI Material & Inköp
- ÄTA
- AI-offert
- Responsiv mobilmeny
- Klickbara demoåtgärder

## Starta lokalt

1. Installera Node.js 20 eller senare.
2. Öppna terminalen i projektmappen.
3. Kör:

```bash
npm install
npm run dev
```

4. Öppna http://localhost:3000

## Viktigt

Detta är en säljdemo med simulerad data. GPS, BankID, leverantörslager,
databas, autentisering och AI-anrop är ännu inte kopplade till riktiga tjänster.

## Nästa steg

- Databas och autentisering
- Verklig projektdata
- GPS-registrering med samtycke och loggning
- Roll- och behörighetsmodell
- API-lager
- Riktiga AI-anrop
- BankID och Fortnox
- Leverantörsintegrationer
