# ÄTA 3.0 – produktionsriktning

## Datamodeller
- change_orders
- change_order_versions
- change_order_lines
- change_order_labor
- change_order_materials
- change_order_attachments
- signature_requests
- signatures
- customer_approvals
- invoice_candidates

## Grundregler
1. ÄTA ska versionshanteras efter kundsignering.
2. Pris och omfattning ska låsas vid godkännande före start.
3. Slutkvittens ska kopplas till utfört arbete och dokumentation.
4. BankID/SMS-status ska loggas med tidsstämpel.
5. Endast fullständigt godkända ÄTA får flyttas till fakturakön.
6. Projektets prognos och marginal ska uppdateras omedelbart.
