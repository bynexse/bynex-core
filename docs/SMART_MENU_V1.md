# Bynex smart menu v1

The customer workspace uses consistent Bynex product names and a shorter main navigation.

- Bynex Start
- Bynex Projekt
- Bynex Personal
- Bynex Tid
- Bynex Arbetsledning
- Bynex Produktion
- Bynex Material
- Bynex Maskiner
- Bynex Connect
- Bynex ÄTA
- Bynex Offert
- Bynex Faktura
- Bynex Bokföring
- Bynex Pärmen
- Bynex Inställningar

Bookkeeping integrations, year-end work and sole-trader functions are grouped inside Bynex Bokföring. The sole-trader section is only available when the active organization's business form is `sole_trader`; it is never shown for a limited company.
